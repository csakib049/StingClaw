# Motion note

The landing hero now animates the existing StingClaw app mock as a short, silent UI documentary: request, work, response, then a proposed change waiting for review. The content comes from the landing page’s current app frame copy and review state; no third party screenshots, invented metrics, generated imagery or audio are used.

The motion is authored with the motionmaxxing seek-safe runtime and plays once when the hero enters view. The final review state remains on screen afterward. Users who request reduced motion see the complete static workspace instead.

This is an in-page HTML motion composition, not a rendered MP4. A video render and the skill’s G0/G2/G3 video gates were not produced. The interactive composition should be reviewed in the browser at desktop and phone widths before publishing.
