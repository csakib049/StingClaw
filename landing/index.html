Nothing changes until you review it

StingClaw stages file edits and shell actions. Review the proposed changes, then approve or reject them.

  • See proposed file changes together with a diff.
  • Approve or reject before changes are applied.
  • Set permissions for each agent.

Agent data is stored locally in SQLite. Prompts are sent to the model provider you choose through OpenRouter.

Questions

Clear answers about where StingClaw runs and what it sends to model providers.

A local app for running named AI agents. Chat through a local web interface or Telegram.

Agent settings and conversation history are stored locally. Messages you send to an agent go to the model provider you choose through OpenRouter. Public web search also sends requests to the configured web search provider.

File edits and shell actions are staged for your review. You approve or reject proposed changes before they are applied.

You can choose models available through OpenRouter and use your own API keys.

You need Bun and an OpenRouter API key. StingClaw currently uses Windows user-level encryption to store API keys, so Windows is the supported platform.
